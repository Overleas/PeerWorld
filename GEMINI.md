# PeerWorld Development Guidelines

## Mod Versioning and Backup Policy (Mandatory)
Before making code changes, updating, or rebuilding the mod:
1. **Always back up the existing `.jar` file** to `/home/overleas/Стільниця/PeerWorld-Backups/peerworld-<version>_<timestamp>.jar`.
2. **Always update `CHANGELOG.md`** describing the new changes, fixes, or additions.
3. **Always report the backup location and changes to the user** in Ukrainian.
